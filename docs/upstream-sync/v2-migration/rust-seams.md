# Rust `ee` crate seam inventory — upstream OneCLI v2.6.0

Source tree: `/Users/marco/Projects/ai-agents/onecli/.claude/worktrees/upstream-ref` (all paths below are relative to `apps/gateway/` unless they start with `packages/`, `docker/`, `.github/` or `apps/gateway-e2e/`).

Purpose: the exact public surface of `crates/ee/ee` (license `LicenseRef-OneCLI-Enterprise`, 5,415 LOC over 22 files) that the Apache-2.0 crates call, so a clean-room replacement crate at the same path/name can be dropped in without touching a free crate.

Headline numbers

- 4 free crates depend on `ee`: `onecli-gateway` (bin), `proxy`, `policy-engine`, `server`.
- 30 distinct `ee::` call sites in free code (comments excluded), reaching **22 public items** across 8 of the 10 ee modules (`cognito`, `kms_crypto` are reached only from the bin's `wiring.rs`).
- 5 free-crate trait seams the replacement must implement: `telemetry::SpendSink`, `context::auth::RoleResolver`, `context::auth::SessionValidator`, `crypto::EnvelopeCrypto`, `cache::CacheStore` + `approval::{ApprovalStore, DecisionWait}`.
- Every entitlement gate lives in FREE code and is passed in as `entitled: bool` / checked before the ee call — except `org_routes` (reads `common::edition::entitled()` itself) and `platform_llm::platform_key()` (reads `common::edition::edition()` itself).
